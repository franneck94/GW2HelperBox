# Changelog

## How To Update

0. Exit from the game and check if GW2 HelperBox++ is still active in Task Manager, if so -> stop it
1. Download the new DLL and place it in addon dir: XXX\GW2\addons\GW2HB
2. Delete all .exe files in addon dir: XXX\GW2\addons\GW2HB
3. Start the game and load the Addon. This will trigger the download of the updated. exe files
4. Restart the game
