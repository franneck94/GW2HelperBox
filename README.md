# GW2 HelperBox++ (GW2HB++)

A Guild Wars 2 helper addon with Trading Post prices, account tools, calculators, and weekly completion tracking.

## First time Installation

1. Download the latest GW2 HelperBox++ release from the [releases page](https://github.com/franneck94/GW2HelperBox/releases)
2. Put it into the Nexus addons directory

## Requirements

- Guild Wars 2 Nexus
